# Upscaler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, local, family-friendly app that upscales images to 4K/6K/8K and videos to 4K on Apple Silicon Macs and Windows/NVIDIA PCs. Photo-real (SeedVR2) is the default for images. Optional bring-your-own-key cloud engines (fal.ai, Replicate, Magnific) come with a guided setup.

**Architecture:**
- A Python package `upscaler` with focused modules: engine (models, tiling, finishing), SeedVR2 engines, video pipeline, cloud providers, and a job queue.
- It is served by FastAPI and a hand-built static web UI.
- Double-click launchers install `uv` and run `python -m upscaler serve`.
- All heavy work runs in one background worker thread, so jobs survive closed browser tabs.

**Tech Stack:**
- Python 3.12 (uv)
- Inference: PyTorch (MPS/CUDA/CPU), spandrel, mflux 0.23 (MLX, Apple Silicon only)
- Web: FastAPI, Uvicorn, vanilla HTML/CSS/JS
- Media: Pillow (<13), pillow-heif, PyAV (probe), imageio-ffmpeg (ffmpeg binary for decode/encode/mux)
- Cloud and keys: httpx, keyring, platformdirs
- Tests: pytest, respx

**Spec:** `docs/DESIGN.md` (with measurements in `docs/RESEARCH.md`). Research prototypes are in `research/` (`tiled.py`, `finish.py` are the reference algorithms).

## Global Constraints

- Python `>=3.12,<3.13`, managed by uv. Pin `pillow>=11,<13`: Pillow 13.0.0 fails to import (`numbers._IntegralLike`).
- `spandrel>=0.4.2,<0.5`. Install `mflux==0.23.0` only with marker `sys_platform == 'darwin' and platform_machine == 'arm64'`.
- Windows torch comes from `https://download.pytorch.org/whl/cu130` (an explicit uv index with marker `sys_platform == 'win32'`). Macs use PyPI torch.
- **Image modes:**

  | id | Model | Notes |
  |---|---|---|
  | `photoreal` | SeedVR2-3B | **Default** |
  | `faithful` | 4xBHI_dat2_real | |
  | `faithful_sharp` | 4xNomos2_hq_dat2 | Under "More modes" |
  | `fast` | 4x-ClearRealityV1 | |
  | `illustration` | RealESRGAN_x4plus_anime_6B | |
  | `cloud:<provider>:<model>` | Cloud | Only when a key is connected |

- **Video modes:** `fast` (ClearRealityV1, **default**), `general` (realesr-general-x4v3), `faithful` (4xBHI_dat2_real; very slow, with a warning).
- **Size presets:**
  - Long-edge presets: `4k` = 3840, `6k` = 6144, `8k` = 8192 (default for images).
  - `8k_tv` fits within 7680×4320 in landscape, or 4320×7680 in portrait.
  - Scale presets: `2x`, `3x`, `4x`.
  - Video always goes to a 3840 long edge, with even dimensions.
- **Output:** JPEG quality 95 with `subsampling=0` by default, or PNG. Keep the ICC profile.
  - RGBA with any alpha < 255: upscale the alpha with Lanczos and force PNG, with a note.
  - Fully opaque RGBA: drop the alpha.
- **Output locations:**
  - Host jobs: `~/Pictures/Upscaled/` (`%USERPROFILE%\Pictures\Upscaled` on Windows).
  - Guest jobs: `<data_dir>/guest/`, deleted 24 h after completion.
  - Filenames: `<stem>-<PRESET>-<mode>.<ext>`, e.g. `table-8K-photoreal.jpg`. On collision add `-2`, `-3`, and so on.
- **Data dir:** `platformdirs.user_data_dir("Upscaler", appauthor=False)`. Models go in `<data_dir>/models`, jobs in `<data_dir>/jobs`.
  - SeedVR2 weights stay in the default Hugging Face cache (`numz/SeedVR2_comfyUI`, files `seedvr2_ema_3b_fp16.safetensors` 6,783,018,808 B and `ema_vae_fp16.safetensors` 501,324,814 B), so the copy already on this Mac is reused.
- **Memory:**
  - DAT2 models: tile 256 (512 used 9.9 GB; 256 uses 2.4 GB at the same speed).
  - Other spandrel models: tile 512, pad 16.
  - SeedVR2 on MLX: never `--low-ram`, because it deletes the transformer after one image. Instead use `MemorySaver(keep_transformer=True, cache_limit_bytes=1_000_000_000)` plus `TilingConfig()`, input tiles ≤ 512 px.
- **Photo-real eligibility:** Apple Silicon with ≥ 16 GB unified memory, or CUDA with ≥ 12 GB VRAM. Otherwise fall back to `faithful`, with the note "Photo-real needs 16 GB of memory; used Faithful instead."
- **Precision:** fp16 if `spec.supports_half` and the device isn't CPU; else bf16 if `supports_bfloat16` and the device is mps/cuda; else fp32. If the first tile's output is non-finite, redo the job in fp32.
- **Network:** no calls except model downloads (official URLs, SHA-256 verified) and cloud calls the user starts. Cloud requests set face enhancement **off**; fal requests send `X-Fal-Store-IO: 0`.
- **Keys:** stored via `keyring` under service `"Upscaler"`, username = provider id, and never written to the project folder. Guests' keys live only in server memory for their session.
- **Server:** default port 7860.
  - `--share` binds `0.0.0.0`; otherwise `127.0.0.1`.
  - Host = request from 127.0.0.1 or ::1.
  - Host-only endpoints return 403 to guests.
- **UI copy:** plain words, no jargon. Photo-real must show "Photo-real invents fine detail. Check faces, logos and text, or switch to Faithful."
- **Credits:** every model's author, licence and link appears on the About page and in `THIRD_PARTY_LICENSES.md`. CC-BY requires this.
- **No git.** The project folder isn't a repository and the user hasn't asked for commits. Skip all commit steps.

## Review Focus

1. **Awkward image files:**
   - transparent or 16-bit PNG, CMYK JPEG, grayscale
   - an EXIF-rotated phone photo
   - an image already at or above the target size
   - a tiny input (<400 px)

   Expected: each one works, orientation is correct, alpha is preserved, and a no-op gets a friendly note instead of a crash. Tests in Task 2.
2. **Batch filename clashes:** two files called `image.png` in one batch, names with spaces or emoji. Outputs must never overwrite each other. Test in Task 2.
3. **Interrupted model download, or disk full:**
   - A `.part` file is resumed or restarted.
   - A hash mismatch deletes the file and shows a friendly error.
   - The cache is never left corrupt.

   Tests in Task 1.
4. **Phone and odd videos:** portrait with rotation metadata, variable frame rate, no audio track, odd dimensions (e.g. 1080×1081), clips under 1 s. Output must be upright with even dimensions and play in QuickTime (`hvc1`). Tests in Task 4.
5. **Two people on Wi-Fi at once:**
   - Concurrent uploads queue in order.
   - A guest closing their tab doesn't stop their job.
   - A guest calling host-only endpoints (keys, settings, open-folder) gets 403.

   Tests in Task 6.

- NVIDIA encoder: `-c:v hevc_nvenc -preset p5 -rc vbr -cq 19 -b:v 0 -profile:v main10 -pix_fmt p010le -tag:v hvc1`.
- Fallback encoder: `-c:v libx265 -crf 18 -preset medium -pix_fmt yuv420p10le -tag:v hvc1`.

### Task 10c: All image formats, server-side inspect and thumbnails (with Task 10b, before Task 11)

**Files:** Modify `upscaler/imageio_utils.py`, `upscaler/server.py`, `upscaler/pipeline_image.py` (only where needed); tests `tests/test_formats.py`.

**Decoder chain** (decided by the coordinator after licence checks):
1. Pillow 12.3 reads JPEG, PNG, WebP, **AVIF (native)**, TIFF, BMP, GIF, JPEG 2000, ICO, TGA, PPM and the PSD composite. pillow-heif reads HEIC/HEIF.
2. `rawpy` 0.27 (MIT; LibRaw is LGPL/CDDL) reads camera RAW: DNG CR2 CR3 NEF ARW RAF ORF RW2 PEF SRW.
3. `resvg-py` (MIT; resvg is Apache-2.0 OR MIT since 0.45) renders SVG straight to the target size. Vectors skip AI: the pipeline renders at the exact target size, then runs finishing and saving, with the note "Vector image: drawn directly at full size, no AI needed".
4. The bundled FFmpeg (`imageio_ffmpeg.get_ffmpeg_exe()`, one frame piped out as PNG) reads EXR, Radiance HDR, DDS and QOI, and PSD when Pillow can't. HDR sources get the note "HDR image converted to standard range".
5. On macOS only, `sips -s format png` is the last resort, for JPEG XL and anything else macOS can read.
6. Otherwise a friendly error. **Not supported:** JPEG XL on Windows (the only Pillow plugin is GPL-3.0); PDF and EPS (the renderers are AGPL or need Ghostscript), with the message "This is a PDF/EPS document. Export the page as PNG or TIFF at the size you need, then drop that in."
